## About Me

Hiii, I'm **Alejandro**. I love technology and everything that uses it to make people's lives easier. I enjoy exploring different operating systems, and I've built things like an AI-powered talking plant and a gesture-controlled desktop app; right now I'm working on a DIY e-reader. In my free time I like learning electronics, soldering PCBs, building useful 3D-printed prototypes, and reading manga.
